# 🎮 Ping Pong Game

An interactive browser-based Ping Pong game built using **HTML, CSS, and JavaScript**.  
The game supports **single-player AI mode and two-player mode** on the same keyboard.

---

## 🚀 Live Demo

Play the game here:  
https://your-vercel-link.vercel.app

---

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- DOM Manipulation
- CSS Animations
- Vercel Deployment

---

## ✨ Features

- 🎮 Single Player Mode (AI opponent)
- 👥 Two Player Mode
- ⚡ Smooth Ball Physics
- 🏓 Paddle Collision Detection
- 📊 Score Tracking System
- 🔊 Sound Effects
- 💥 Particle Effects
- 🌀 Ball Trail Animation
- ⏸ Pause / Resume Game
- 🔄 Restart Game Button
- ⚡ Adjustable Ball Speed
- 🎁 Power Ups
  - Double Ball
  - Slow Motion

---

## 🎮 Game Controls

| Player | Controls |
|------|------|
| Player 1 | W / S |
| Player 2 | Arrow Up / Arrow Down |
| Pause Game | P |
